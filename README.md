# JARVIS — Project Blueprint

This repository's root is a static cinematic project-roadmap site for the JARVIS Android AI Agent.

## Landing page
- `index.html` — responsive blueprint landing page, 3D animated core, architecture overview, interactive milestone checklist.
- Checklist progress is saved in local browser storage.
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment on pushes to `main`.

## Deploy
1. Open **Settings → Pages**.
2. Set the publishing source to **GitHub Actions** (if it is not already selected).
3. The Pages workflow deploys automatically after a push to `main`; check **Actions** for the deployment status.

The original repository contents were replaced on the current branch. Git history is retained.
