03 / ECOSYSTEM

One interface.
Multiple pathways.

JARVIS can be configured around different AI services and optional companion integrations. Treat the app as a hub you configure, rather than a magical system with every service already connected.

  • Hosted AI: use compatible provider services with their own account and API setup.
  • Local endpoints: connect supported local infrastructure when it is available.
  • Termux companion: optional advanced local worker setup.
  • Telegram / Home Assistant: optional integrations with separate configuration.

Provider costs, data handling and service limits are determined by the connected service. Review each provider's terms and privacy policies.
