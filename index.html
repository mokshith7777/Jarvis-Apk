03 / ECOSYSTEM

One interface.
Multiple pathways.

JARVIS can be configured around different AI services and optional companion integrations. Treat the app as a hub you configure, rather than a magical system with every service already connected.

  • Hosted AI: use compatible provider services with their own account and API setup.
  • Local endpoints: connect supported local infrastructure when it is available.
  • Termux companion: optional advanced local worker setup.
  • Telegram / Home Assistant: optional integrations with separate configuration.

Provider costs, data handling and service limits are determined by the connected service. Review each provider's terms and privacy policies.

Download only from the official JARVIS distribution page. Before installing, check the release name, version, file size and any published checksum or signing information. Don't install an APK forwarded by an unknown person or a file with a different name/version.

SECURITY FIRSTIf Android or Play Protect shows a warning, stop and verify the release. Do not disable Play Protect or ignore a harmful-app warning to force installation.

If Android says installation is not allowed from this source, open the permission prompt for the app you used to download/open the APK. The setting is usually called Install unknown apps or Allow from this source, under Apps or Special app access.

Allow it only for the trusted source you are using, return to the APK, and continue. Turn the permission back off afterward if you no longer need it.

Tap the APK in Downloads, review the installer screen and choose Install. Wait for completion, then open JARVIS. If installation fails, check that the APK supports your Android version and CPU architecture, that there is enough storage, and that you are not trying to install an older build over a newer one with a different signing key.

Set your preferred language and interface options. Start with a simple text message before configuring voice, background behavior or integrations. Confirm the app responds and that its settings screen is accessible.

Choose a provider that the installed build supports. Read that provider's privacy, usage and billing terms. Enter credentials only inside the intended provider configuration screen. Never paste API keys into public chats, screenshots, logs, or share them with anyone. If you do not have a provider configured, use the app's available demo/local mode if present.

When you first use voice input, Android may ask for microphone access. Grant it only if you intend to use voice. Test with the app open, in a quiet environment. Check media volume, speech output settings and your chosen language if voice responses are silent or recognition is inaccurate.

You can revoke microphone permission at any time from Android App info → Permissions. Voice may not work when the app is closed unless the installed version explicitly supports background listening.

Some advanced features may require additional services or powerful permissions. Accessibility access can allow an app to read interface content and perform actions on your behalf. Enable it only when the exact feature is clearly explained, the app source is verified, and you understand the scope. This guide does not recommend bypassing Android restricted-settings protections or security warnings.

POWERFUL PERMISSIONIf a feature asks for Accessibility, Restricted settings, device-admin access, or broad control, pause and verify what it does. Ask a trusted adult or knowledgeable person to review the request if you're unsure. Optional integrations can remain disabled.

Termux companions, Telegram, Home Assistant and local endpoints are separate optional systems. Each needs its own setup and should not be assumed to work automatically.

For features that need background operation, check App info → Battery and Notifications. Menu labels vary. Start with default/recommended battery settings; only change background restrictions for a feature you actively use and understand. Persistent background activity can affect battery life.

DEVICE NAVIGATION TIPUse the Settings search box for terms such as “App battery usage”, “Background activity”, “Notifications”, or the app name. Manufacturer menus move these controls around between updates.
  • App won't install: verify source, compatibility, storage and signature consistency.
  • App closes: update to a verified compatible release, restart device, check available storage.
  • No voice: check microphone permission, volume, language and network/provider requirements.
  • Slow response: check network, provider status, model selection and service limits.
  • Battery drain: disable optional always-on features you aren't using; review app battery usage.
  • Warning screen: don't bypass it. Verify the APK and contact the publisher for clarification.
