05 SYSTEM NOTES

BEFORE YOU
DEPLOY.

Does JARVIS work fully offline?

Not necessarily. Offline operation depends on the configured model and features. Hosted providers and online services require connectivity.

Do I need an API key?

Some hosted providers require keys and may charge according to their own pricing. Requirements depend on the provider or endpoint.

Is Termux required?

Termux companion functionality is optional and intended for advanced configurations.

Are integrations ready out of the box?

Optional integrations require compatible services and their own configuration, credentials and permissions.

Is this a production-ready release?

The currently documented public build is experimental. Verify signing, compatibility, security and release readiness before relying on it.
